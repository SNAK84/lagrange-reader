# Lagrange Reader RU 2.2.0-ru.1

Русская сборка на основе стабильного Lagrange Reader 2.2.0 (26 ноября 2026).

- Сохранена русская локализация и исправления предыдущей сборки.
- Добавлена поддержка Grimmory и улучшения Android Auto из оригинального релиза.
- Отдельный идентификатор приложения: `com.vangeaux.lagrange.ru`.
- Обновления направлены на релизы SNAK84/lagrange-reader; проверяются версия, пакет и сертификат.

Универсальный APK подходит для всех поддерживаемых архитектур. Если установленная тестовая сборка подписана другим ключом, Android потребует её удалить перед установкой. Сохраните важные данные заранее.

[Изменения оригинала 2.2.0](https://github.com/van-geaux/lagrange-reader/blob/v2.2.0/docs/release-notes/v2.2.0.md)
